# 大会情報バックエンド（Googleスプレッドシート）セットアップ手順

`Code.gs` を Google Apps Script の Web アプリとして公開するための、最初の1回だけ必要な設定手順です。
（この作業はGoogleアカウントの操作を伴うため、担当者が実際にブラウザで行う必要があります）

## 1. 新しいGoogleスプレッドシートを作る

1. `ishikawaboundtennis@gmail.com` でログインした状態で [sheets.google.com](https://sheets.google.com) を開く
2. 「空白のスプレッドシート」を新規作成
3. わかりやすいタイトルに変更する（例：「バウンドテニス協会HP_大会データ」）

## 2. Apps Script を貼り付ける

1. メニューの「拡張機能」→「Apps Script」を開く
2. 開いたエディタに元々ある `function myFunction() {...}` を全部消す
3. このフォルダの `Code.gs` の中身を全部コピーして貼り付ける
4. 上部の「プロジェクト名」を「大会データAPI」などに変更
5. フロッピーアイコン（保存）をクリック

## 3. 初期設定用の関数を1回だけ実行する（ヘッダー行の作成）

1. エディタ上部の関数選択ドロップダウンで `setup` を選ぶ
2. 「実行」ボタンを押す
3. 「承認が必要です」と出たら「権限を確認」→ 自分のGoogleアカウントを選択 →
   「詳細」→「（プロジェクト名）に移動（安全ではないページ）」→「許可」
   - ※これは自分たちで作ったスクリプトなので問題ありません。Googleの標準的な確認画面です。
4. 実行が完了したら、スプレッドシートに戻り「events」という名前のシートが増えていて、
   1行目にヘッダー（id, date, dateEnd, ...）が入っていることを確認する

## 4. Web アプリとしてデプロイする

1. エディタ右上の「デプロイ」→「新しいデプロイ」をクリック
2. 歯車アイコン（種類の選択）→「ウェブアプリ」を選ぶ
3. 以下のように設定する

   | 項目 | 設定値 |
   |------|--------|
   | 説明 | 大会データAPI v1 |
   | 次のユーザーとして実行 | 自分 |
   | アクセスできるユーザー | 全員 |

4. 「デプロイ」ボタンを押す
5. 再度Googleの承認画面が出た場合は手順3と同様に許可する
6. 完了すると「ウェブアプリのURL」が表示されるので、**このURLをコピーする**
   （`https://script.google.com/macros/s/...../exec` という形式）

## 5. コピーしたURLを教えてください

このURLを Claude に伝えてください。`index.html` 内の `SHEETS_API_URL` にこのURLを設定し、
管理画面の保存先がこのスプレッドシートになるように反映します。

## 6. Googleサインインの設定（管理画面へのログインに使う「鍵」の発行）

管理画面へのログインをパスワードではなく、協会のGoogleアカウントで行うようにするための設定です。
Google Cloud Console でしか発行できないため、担当者が実際にブラウザで行う必要があります。

1. `ishikawaboundtennis@gmail.com` でログインした状態で [console.cloud.google.com](https://console.cloud.google.com) を開く
2. 上部の「プロジェクトを選択」→「新しいプロジェクト」→ 名前を「ibta-hp」などにして作成
3. 左メニュー「APIとサービス」→「OAuth同意画面」
   - User Type: 「外部」を選択→作成
   - アプリ名: 「石川県バウンドテニス協会 管理画面」、サポートメール・デベロッパー連絡先: `ishikawaboundtennis@gmail.com`
   - スコープ画面はそのまま「保存して次へ」
   - テストユーザーの画面で「+ ADD USERS」→ `ishikawaboundtennis@gmail.com` を追加
   - 公開設定は「テスト」のままでOK（Googleの審査は不要）
4. 左メニュー「認証情報」→「+ 認証情報を作成」→「OAuthクライアントID」
   - アプリケーションの種類: 「ウェブ アプリケーション」
   - 名前: 「ibta-hp admin」など
   - 「承認済みのJavaScript生成元」に、実際に公開するホームページのURL
     （例：`https://6x6x6hollow6x6x6-creator.github.io`）を追加
   - 「作成」をクリック
5. 表示される「クライアントID」（`〇〇〇.apps.googleusercontent.com` の形式）をコピーする
   - これはパスワードと違って公開しても問題ない値です
6. このクライアントIDを Claude に伝えてください。`index.html` の `GOOGLE_CLIENT_ID` と
   `Code.gs` の `GOOGLE_CLIENT_ID` の両方に同じ値を設定します
7. `Code.gs` 側の `ALLOWED_EMAILS` に、管理画面へのログインを許可するGoogleアカウントの
   メールアドレスを追加・変更できます（担当者が増えた場合はここに追記）

## 補足：コードを更新したとき

将来 `Code.gs` の中身を修正した場合、貼り付け直すだけでは反映されません。
「デプロイ」→「デプロイを管理」→ 該当のデプロイの鉛筆アイコン →
「バージョン」を「新バージョン」に変更 →「デプロイ」を押す必要があります
（URLは変わりません）。
